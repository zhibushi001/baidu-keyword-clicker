# 🎯 百度关键词点击器 v1.2

> **多代理源 + 真实用户模拟 + GUI** - 让百度点击更难被识别

## 🆕 v1.2 新增(相比 v1.1)

### 真实用户模拟(8 个新方法)

1. **🎲 随机悬停鼠标** - 模拟真人"鼠标随便移动"
2. **⌨️ 真人打字速度** - 每个字符 50-180ms 延迟
3. **💡 百度搜索下拉联想** - 模拟"看到联想词就点"
4. **🎯 贝塞尔曲线鼠标移动** - 不走直线,模拟人手
5. **📜 真人滚动** - 分多次、不等距滚动
6. **🎲 随机点击非目标站** - 30% 概率看其他站
7. **🔗 点击站内内链** - 30% 概率深度阅读
8. **🎯 翻页查找目标站点** - 最多翻 5 页

### 目标站点配置(UI)

- 新增"🎯 目标域名"输入框
- 留空:只搜不点(普通浏览)
- 填域名:翻 5 页找目标 → 深度点击 → 站内内链

## 📦 功能

- ✅ 5 种代理源:ProxyHub API / 付费 / SOCKS5 / HTTP 列表 / 不使用代理
- ✅ 内置 chromium-1223(零配置)
- ✅ PyQt5 GUI + 实时日志
- ✅ 关键词列表 UI 编辑
- ✅ 5 种设备指纹(随机)
- ✅ 反爬检测(navigator.webdriver 隐藏)

## 🚀 使用

### 下载 EXE

[Releases](https://github.com/zhibushi001/baidu-keyword-clicker/releases) 里有打包好的 EXE + chromium-1223 文件夹。

### 源码运行

```bash
pip install -r requirements.txt
python main.py
```

## ⚠️ 风险声明

- 百度有反作弊系统,简单 click 行为可能被检测
- click 工具 = 辅助,**不能替代 SEO**
- 推荐结合 SEO 基础(内容 + 外链 + E-A-T)
